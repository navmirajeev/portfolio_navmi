# Navmi Rajeev · Portfolio
URL:https://portfolio-navmi.vercel.app/
Personal portfolio website showcasing my work across **Artificial Intelligence, Machine Learning, Computer Vision, Vision-Language Models and research**.

The site combines a minimal editorial design with interactive motion, smooth scrolling and WebGL-based visual effects.

## ✦ Featured Work

### VLM Research

Research into visual-language conflict and attention-head arbitration, exploring whether lightweight adaptive head weighting can reduce cases where language priors override visual evidence.

**Tech:** PyTorch · Qwen2.5-VL · Vision-Language Models · Research

### MarketLens

A financial intelligence system exploring retrieval-augmented generation for connecting current financial events with historical market context.

**Tech:** Python · RAG · LLMs · AI

### Spotify Song Recommendation using Emotion Detection

A computer vision system that detects facial emotions and uses them to provide music recommendations.

**Tech:** Python · OpenCV · DeepFace · Streamlit

### Prototype Pandemic Defense System

A CNN-based medical imaging system exploring automated disease prediction from medical images.

**Tech:** Deep Learning · CNNs · Computer Vision

### Alternate Medicine Finder

An AI-based system exploring information retrieval and recommendation for alternative medicine use cases.

**Tech:** Machine Learning · AI · Healthcare

### Harvesting Insights

An explainable AI project focused on extracting insights from agricultural data and making machine learning predictions more interpretable.

**Tech:** Machine Learning · Explainable AI · Agriculture

## ✦ Getting Started

Clone the repository:

```bash
git clone https://github.com/navmirajeev/portfolio_navmi.git
cd portfolio_navmi
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

Create a production build:

```bash
npm run build
```

Run the production server:

```bash
npm start
```
